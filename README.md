# Any Video Download

通用媒体检测扩展（Chrome / Edge，Manifest V3）。当前版本 1.2.3。

1.2.3 修复并发扫描丢失播放器时长、资源扫描覆盖已有元数据的问题；补充继承来源的 about:blank/blob frame 和开放 Shadow DOM 中的播放器扫描。侧栏独立显示页面播放器时长，只有实际播放地址与下载条目匹配时才标为“已关联下载条目”并优先展示；未匹配的 blob 播放器明确提示尚未关联下载地址。此提示不代表已经取得完整视频，不会仅凭时长将广告关联为正片。更新后需要重新加载扩展并刷新网页。

1.2.2 修复广告切换后漏扫：资源观察器直接读取新请求，扫描采用节流而非无限延迟的防抖，初始资源按 100 条分批发送；播放器换源或时长显著变化时重新解析同一 frame 的已知播放列表，常规播放列表缓存最多保持 10 秒后可重验。新发现的视频排在前面，网页视频页始终提供“重新扫描”。不会仅凭时长把短视频判为广告；广告与正片使用不同地址时两者可能同时列出。私有传输、DRM 或服务器把广告直接拼入正片的情形仍不保证自动区分。

1.2.1 修正侧栏消息来源字段缺省时的处理，并要求后台明确确认下载任务。点击后显示“正在提交”，后台拒绝、没有返回或超时都会在侧栏显示错误，不再依赖弹窗或静默切到空记录页。

## 在当前电脑使用

1. 在 `chrome://extensions` 找到 **Any Video Download**，点击重新加载。
2. 刷新需要识别视频的网页，再播放视频，然后重新打开扩展侧栏。
3. HLS / DASH 可以选择清晰度，使用本地 FFmpeg 助手输出 MP4；普通视频文件交给浏览器下载。

本地助手已为当前扩展注册。下载由扩展后台管理，关闭侧栏仍可继续；请保持浏览器运行。流媒体文件保存在系统“下载”文件夹。重新加载扩展或退出浏览器会中断流媒体任务，记录会标为中断。

侧栏的“下载记录”页显示进度条、百分比、处理时长、已写入大小、处理速度和完成路径。普通文件按下载字节计算进度，流媒体按已处理时长计算；未知总时长显示不定进度，只有文件实际完成才显示 100%。下载记录使用本地存储，侧栏重开或浏览器重启后仍保留；旧版没有记录的下载不会自动补录。记录不保存媒体签名链接或登录凭据。

完成记录可复制保存路径，浏览器下载的文件还可以直接在文件夹中显示。取消原生流媒体下载会删除未完成文件。

## 已实现

- 通过响应 MIME、URL 和页面 video/source 元素发现媒体，覆盖 iframe。
- HLS 主列表、清晰度列表、独立音轨解析；按清单里的真实引用关系归组，不按网页标题合并不同视频。
- HLS 时长、直播和保护格式识别；DASH 清晰度、时长和保护标记识别。
- 排除 TS / M4S 等分片，并移除已识别 HLS 清单引用的 MP4 分片。
- 仅普通文件展示响应文件大小，206 响应用 Content-Range 总大小。
- 串行更新同一标签页存储，防止并发响应互相覆盖；清空与页面跳转后拒绝旧解析结果写回。
- 页面直接提供媒体地址时关联封面、时长、标题；不把无法确认归属的封面强行绑定到其它视频。
- FFmpeg 合并 HLS 独立音视频轨；DASH 通过 ffprobe 匹配选择的分辨率。

## 当前边界

- 不保证覆盖所有网站。DRM、私有传输协议（例如 YouTube UMP）不作为可直接下载的 MP4。
- 需要 Cookie / 自定义 Authorization 请求头、严格防盗链的网站可能解析或下载失败。目前不会导出浏览器 Cookie 给本地助手。
- blob URL 本身不是下载地址；依赖其背后的 HLS/DASH/媒体请求。无法确定关联时，封面留空、标题使用网页标题。
- DASH SegmentTemplate 片段常见的 `.m4s` 会被过滤；非标准无后缀/MP4 分片的全面关联仍有限。
- 直播不提供有限时长文件，本版侧栏禁用直播下载。
- FFmpeg 使用流复制；不兼容 MP4 容器的编码会明确报错，不会伪装为成功。
- 当前机器使用已有的 `DownloadHelper CoApp/ffmpeg.exe` 和 `ffprobe.exe`，卸载该软件后需改为其它 FFmpeg 安装路径重新注册。

## 其它电脑安装助手

需要 Node.js、FFmpeg 和同目录的 ffprobe.exe。扩展 ID 可在扩展管理页查看。

```powershell
./native/install.ps1 -ExtensionId <扩展ID> -FfmpegPath 'C:\ffmpeg\bin\ffmpeg.exe'
```

安装脚本仅注册当前用户的 Chrome/Edge Native Messaging 主机。仅允许指定扩展调用；不启动监听端口。可用 `native/uninstall.ps1` 移除注册。
