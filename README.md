# Any Video Download

**一个免费开源的视频下载插件，帮你下载大部分常见网站上的视频。**

打开网页、播放视频，插件就会自动寻找可下载的视频。选好清晰度，点击下载，就能保存到电脑，方便随时观看。

- **适用网站广**：不用为不同网站反复寻找下载工具。
- **操作简单**：自动识别视频，点击即可下载。
- **清晰度可选**：按需要选择视频提供的清晰度。
- **进度看得见**：随时查看下载进度和历史记录，下载后直接打开视频或所在文件夹。
- **免费开源**：代码公开，欢迎使用和改进。

支持 Chrome 和 Edge。部分网站的视频可能因访问限制或网站更新而无法下载。
